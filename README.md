# 中文个人风格蒸馏 · Chinese Personal Voice

**让 AI 学会你怎样解释、怎样判断、怎样把话说清楚。**

把你自己的讲话转写、聊天和原创文章，提炼成有原句依据的九维风格档案。以后写公众号、文章、报告或论文时，既保留个人表达，也遵守不同文体的要求。你说一句“这句话不像我”，它还能把明确的纠正记录下来，逐步更新。

这是一个面向 Codex 的可复用 Skill，包含中文分析流程、档案模板、来源校验和本地工具。这里的“蒸馏”指**从语料提炼规则与示例**，不训练或微调模型权重。

[使用流程](#怎么用) · [九个维度](#它具体学什么) · [安装](#安装) · [隐私与边界](#隐私与边界) · [来源与许可](#来源与许可)

## 为什么要做这个

“写得自然一点”“去掉 AI 味”通常只能得到一种通用的自然表达。个人风格还包括：你会先问什么、怎样举例、什么时候下判断、如何照顾读者的理解过程。

这个 Skill 把这些习惯变成可回查的规则。例如，某位作者的原文反复出现“先说明具体问题，再拆开原因，最后给一个可检验的做法”，档案就记录这种展开方式，而不是只要求多加几个口头禅。

以下是**合成演示，不是作者原话，也不是每个人都要采用的风格**：

> 通用表达：应充分利用人工智能提升工作效率，形成持续优化的闭环。
>
> 某种个人表达：先挑一件你每天都在重复做的事。比如整理会议记录。让 AI 帮你做一次，再看看它省了哪一步、哪一步还要你检查。这样试两次，你就知道它到底有没有帮上忙。

真正的写法由你的材料决定，不照搬这个例子。

## 它具体学什么

| 维度 | 观察的问题 |
| --- | --- |
| 词汇与搭配 | 你常用什么连接词、指代和解释用语？哪些只是话题名词？ |
| 句式与语序 | 先说判断还是先铺垫？怎样设问、补充、转折？ |
| 节奏与信息密度 | 一个句群推进多少意思？哪里重复，哪里收住？ |
| 思路展开 | 怎样从问题走到解释，再走到结论或行动？ |
| 解释与论证 | 怎样用例子、类比、反例和限制条件？ |
| 语气与判断力度 | 哪些话说得直接，哪些保留“可能”“通常”？ |
| 听众关系 | 怎样用“我、你、我们”，怎样回应读者的疑问？ |
| 情绪与修辞 | 怎样强调、幽默、自嘲；哪些表达依赖当时场景？ |
| 场景与边界 | 同一个人在课堂、公众号、报告和论文里怎样变化？ |

每条规则需要来源、原句、适用范围和证据等级。没有足够依据的维度可以保留“待观察”。

## 怎么用

### 1. 提供你自己的材料

可以从几段真实讲话或几篇原创文章开始，不设固定篇数门槛。材料越能覆盖不同日期、话题和用途，越容易区分稳定习惯与偶然表达。

你可以这样说：

> 使用 chinese-personal-voice。这些是我的原始讲话转写和原创文章。请先核对作者、整理场景、去重，再建立有原句依据的风格档案。AI 整理稿另放，别算作我的原创。

多人录音先分离本人发言；转写没有校对，就不把软件添加的标点当成本人的标点习惯。录音转写本身由已有且获授权的工具处理，本 Skill 不包含语音识别服务。

### 2. 蒸馏并试写

流程是：**核对来源 → 去重分组 → 中文统计 → 九维规则 → 新题或留出资料验证 → 本人纠正**。

档案包括：

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 记录语料来源、作者、场景、训练/留出划分 |
| `profile.json` | 可执行风格规则、证据、适用范围与版本 |
| `voice.md` | 便于阅读的个人表达说明 |
| `examples.md` | 原句索引；AI 试写另外标记 |
| `metrics.json` | 按明确口径计算的中文统计 |
| `feedback.jsonl` / `history/` | 明确纠错记录与历史版本 |

档案分为 `untrained`（未建立）、`provisional`（初版待本人验证）、`calibrated`（指定场景已通过本人评审）。结构检查通过不等于已经像你，也不等于所有文体都已校准。

### 3. 写作和持续纠错

> 按我的个人风格档案，把这份事实材料写成公众号文章。保留我的解释顺序和措辞习惯，不增加材料里没有的经历与数据。

> 这句话不像我。以后写这个科技号时，别先堆三个抽象判断，直接从具体问题讲起。

纠错默认先改本稿；“以后这个号都……”才升级为该账号的长期规则。明确要求所有文体都适用时再跨场景使用。论文保留你的论证与解释习惯，同时保留专业术语、引用和准确的判断力度。

## 安装

把本仓库交给 Codex：

```text
请从 https://github.com/liuyu00347-sudo/chinese-personal-voice
安装 chinese-personal-voice Skill。保留我已有的本机设置和个人档案。
```

也可以下载本仓库 ZIP，将解压文件夹命名为 `chinese-personal-voice`，放入你的 Codex Skills 目录。本项目已在 Codex 的本机 Skills 环境验证；其他支持 `SKILL.md` 的工具可能需要适配安装目录和默认调用规则。

安装后，在 Skill 文件夹创建**仅本机保存**的 `settings.local.json`：

```json
{
  "profile_root": "/absolute/path/to/your/private-voice-profile"
}
```

然后让 Codex 初始化并维护这个固定位置。不要把个人档案放在本仓库里。多个写作任务应复用同一个档案；安装 Skill 本身不保证每个客户端都会自动调用。需要默认使用时，把下面的约定加入你自己的全局或项目协作规则：

> 为我本人署名撰写或改写中文文章、公众号、论文、报告和口播稿时，默认使用 chinese-personal-voice 和我指定的同一份档案。本次明确要求优先，普通问答、纯翻译和仅改格式不强制套用。

### 可选：本地工具

需要 Python 3.10+，仅用标准库。将下列 `SKILL`、`PROFILE` 换成实际路径：

```bash
python3 "SKILL/scripts/voice_tool.py" init --root "PROFILE" --author-id default
python3 "SKILL/scripts/voice_tool.py" metrics --manifest "PROFILE/manifest.json" --output "PROFILE/metrics.json"
python3 "SKILL/scripts/voice_tool.py" validate --root "PROFILE"
python3 "SKILL/scripts/voice_tool.py" check --root "PROFILE" --draft "稿件.md" --context wechat --output "检查.json"
```

`init` 拒绝覆盖已有档案。统计不做语言学分词，字符片段不冒充词频；检查结果只提供漂移线索，不给“95% 相似度”或“AI 率”。完整命令与数据格式见 [数据约定](references/data-contract.md)。

## 隐私与边界

- 本仓库只提供可复用方法、工具和空白模板，**不包含作者或任何用户的真实录音、聊天、课堂原话、私人风格档案**。
- 本地脚本不联网、不上传文件。AI 阅读材料仍会经过你当前使用的模型服务，整个流程不能称为完全离线。
- 只使用你提供或明确指定的资料；不会自行扫描硬盘、邮箱或聊天记录寻找素材。
- AI 草稿、改写稿和他人作品不能自动混入本人原创基线。原文里的旧事实、经历和立场也不能被带进新文章。
- 文字转写不能可靠证明真实语速、重音或停顿时长。单一场景的录音不能证明作者在所有文体中都这样表达。
- `.gitignore` 是防误提交的辅助措施；公开前仍应检查实际提交清单与历史。
