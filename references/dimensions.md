# 九维中文个人表达分析

先分场景，再找稳定项。只分析可观察的语言行为，不诊断人格、潜意识或心理状态。

| ID | 对象 | 提取方式 |
|---|---|---|
| D01 | 用词与搭配 | 对照日常/书面词、连接词、指代、惯用表达和同义替换。题材名词另列，不能当风格证据。 |
| D02 | 句式与语序 | 先结论/先铺垫、主语省略、插入补充、并列因果、设问、主动被动。完整句连同上下文取证。 |
| D03 | 节奏与信息密度 | 字符句长分布、句群、停顿、重复、每段推进几个意思。信息密度需解释句子功能，不只看长度。 |
| D04 | 思路展开 | 从经历/问题/判断切入，怎样转折、展开和收尾。提炼反复出现的内容骨架，避免固定套模板。 |
| D05 | 解释与论证 | 类比、实例、反例、数据、亲身经历、引证与限制条件；区分他人论证和本人组织方法。 |
| D06 | 语气与判断力度 | 肯定、保留、让步、异议；对照“可能/通常/一定”等作用，不改变事实的确定程度。 |
| D07 | 听众关系 | 我/我们/你、称呼、解释前提、互动、礼貌和距离。记录对谁说、为何说。 |
| D08 | 情绪与修辞 | 情绪强弱、幽默、自嘲、反问、比喻、夸张；附原句与作用，不人为补情绪。 |
| D09 | 场景与边界 | 共性和各场景差异，明确不用的表达；“本人排斥”和“尚未观察到”分开。 |

## 可执行规则

不用“亲切、自然、有温度”替代具体做法。规则示例：“解释陌生概念时先给具体情境，再命名概念”。这只是演示，不能写入本人档案，除非真实资料支持。

引文逐字保留，能回到来源。修订 ASR 错误保留原始文件和修订记录。本人原句与 AI 仿写分别标注。

置信等级：
- tentative：单例或证据不稳定，轻量参考。
- supported：至少两个独立来源反复出现且作用一致。
- user_confirmed：用户明确确认具体规则与范围，关联反馈事件。
这是证据等级，不是概率。all 范围至少需要两个场景的证据或用户明确跨场景授权。单场景只描述该场景。

AI 生成稿、本人修改过的 AI 稿和他人作品可作指定参考/偏好对照，但不能自动成为本人原创基线。
